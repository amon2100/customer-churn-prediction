# Customer Churn Prediction

Explore and model customer churn using the Telco customer dataset, pandas, and scikit-learn.

The notebook loads and explores the Telco customer data, cleans `TotalCharges`, prepares numeric and categorical features, and creates a stratified train/test split for churn classification.

## Project files

- `customer_churn_prediction.ipynb` - data exploration and churn-prediction workflow.
- `WA_Fn-UseC_-Telco-Customer-Churn.csv` - dataset used by the notebook.

## Getting started

1. Create and activate a Python virtual environment.
2. Install the dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Start Jupyter:

   ```bash
   jupyter notebook
   ```

4. Open `customer_churn_prediction.ipynb` and run the cells.

The notebook expects the CSV file to be in the project directory.
